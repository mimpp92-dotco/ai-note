# src — Next.js 앱 (UI · API · 핵심 계약)

상위 진입점: [../AGENTS.md](../AGENTS.md) · 전체 계약: [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)

## 목적 Purpose / Owns
녹음 UI, HTTP API 라우트, 그리고 프로젝트의 순수 도메인 계약(타입·FSM·zod 스키마)을 소유한다. 교정·요약은 백그라운드 워커가 사용자의 로컬 CLI(claude/codex)·Ollama로 수행한다($0 — API 키 미저장).

- `src/app/` — 페이지(`src/app/page.tsx`, `src/app/meetings/[id]/page.tsx`, `src/app/glossary/page.tsx`) + 앱 셸 `src/app/layout.tsx`(좌측 `LibraryNavigation` rail + skip-to-content) + API 라우트 핸들러(`src/app/api/meetings/route.ts`, `src/app/api/meetings/[id]/title/route.ts`, `src/app/api/glossary/route.ts`, `src/app/api/transcribe/route.ts` 등, 모두 Node 런타임). 회의 삭제는 `meetings/[id]/route.ts`의 `DELETE`.
- `src/components/` — app-level native top-layer `AppDialog`/`AppDrawer`(`__tests__/AppDialog.test.tsx`), horizontal controlled `Tabs`(`__tests__/Tabs.test.tsx`), layout-scoped `RecorderSessionProvider`(MediaRecorder/retained Blob/navigation guard)와 `LibraryProvider`(version/freshness/bounded pages), view `Recorder`, `GuardedLink`/`useGuardedRouter`, `HomeClient`, `MeetingList`/`MeetingRow`/`EditableTitle`, `MeetingDetailView`, `GlossaryClient`, 공유 헬스 훅 `useHealth`(whisper·LLM 폴러 1개, endpoint별 in-flight dedup) 등. `MeetingDetailView`는 title/metadata → notice → action → audio/review → Tabs/panel 순서와 저장 직후 participants copy freshness를 소유한다. `LibraryPrimitives`는 `AppDialog`를 감싸는 `LibraryDialogShell` 하나만 노출한다.
- `src/domain/` — 무의존 타입/FSM/스키마(`src/domain/meeting.ts`, `src/domain/library.ts`, `src/domain/libraryRecoveryIntent.ts`, `src/domain/libraryRecoveryPlanner.ts`, `src/domain/summarySchema.ts`, `src/domain/glossary.ts`). Library structural invariant, runtime `StatusJson`, meeting-record 분류는 `domain/library.ts`가 소유하고 recovery parser/planner는 filesystem을 열지 않는다.
- `src/lib/` — 유틸(`durableFileOps`, `library`, `status`, `meetingLifecycle`, `artifactLease`, `artifactPair`, `audioStream`, `finalizeRecord`, `finalizePlacement`, `summarizeCore`, `summarizePublisher`). `audioStream`은 single byte-range 정규화와 Node→Web backpressure/settle-once release를 소유한다. `library.json`은 library repository, `glossary.json`은 app-api 단일 writer다.
- `src/services/` — 외부 래퍼(`src/services/whisperClient.ts` + LLM 백엔드 `src/services/llm/`: `claudeCli`·`codexCli`·`ollama`·`exec`·`index`(factory)·`types`·`fake`). claude/codex health는 `--version` 바이너리 감지(“감지됨”)이고, 생성 호출은 `LLM_GENERATION_TIMEOUT_MS`(600초)로 실행한다. `claudeCli.run()`은 invocation별 `mkdtemp` cwd + best-effort cleanup, 인라인 MCP-off/slash-off, `$0` env 스크럽을 적용한다(ADR 0010).

## 자주 하는 변경 Common changes (patterns)
- **새 API 라우트**: `src/app/api/**/route.ts`에 추가. **주의(build-green)**: `data/`를 읽으면 `export const dynamic='force-dynamic'` + fetch는 `cache:'no-store'`; top-level `process.env` 접근 금지(핸들러 내 지연); edge 런타임 금지.
- **Data surface**: 새 route/RSC를 `DATA_SURFACE_INVENTORY`에 등록하고 첫 side effect 전에 `guardLocalApiRequest()`/page guard를 호출한다. JSON은 `parseBoundedJsonBody()`, status 응답은 `toPublicMeeting*()`, 오류는 static `publicErrorResponse()`를 사용한다. Internal `StatusJson` spread, path/job/attempt/raw Error 응답·로그 금지.
- **상태 전이**: `status.json`은 **app-api만** 쓴다(단일 writer). FSM은 `src/domain/meeting.ts` 참조.
- **삭제 fence**: `meetingTombstone.ts`만 tombstone을 쓰고 `meetingCleanup.ts`가 placement/live directory/deterministic trash를 재시도한다. ID를 다루는 새 read/write surface는 body/fs 전 `meetingFenceResponse()`를 호출하고, status updater 방어를 우회하지 말 것.
- **Finalize 발행**: `finalizeRecord.ts`만 hidden intent/audio/status/receipt를 만들고 canonical meeting directory를 publish한다. Body 전 intent, operation→artifact lease, receipt-only final invariant를 지킨다. `finalizePlacement.ts`는 latest canonical placement를 우선하며 pending/unavailable record를 generic reconcile에 먼저 materialize하지 말 것.
- **Recorder/session navigation**: route component에서 MediaRecorder/Blob을 소유하지 않는다. `RecorderSessionProvider`가 stable ID, start 시점 canonical location snapshot, retained Blob과 finalize metadata를 layout lifetime으로 보존한다. Ambiguous upload는 bodyless same-ID probe가 `body_required|not_committed`를 확인하기 전 재전송하지 않는다. 모든 client navigation surface는 `GuardedLink` 또는 `useGuardedRouter`를 사용하고 scope-query-only 이동 외에는 확인된 explicit discard 없이 unsaved session을 잃게 만들지 말 것.
- **Modal/drawer surface**: 새 modal은 fixed/z-index/document key listener를 만들지 말고 `AppDialog`/`AppDrawer`를 사용한다. Feature가 initial focus와 success destination을 선택하고 primitive가 native cancel/backdrop, user-dismiss focus return, nested ref-count body scroll lock을 맡는다. Mutation 중에는 `dismissible=false`와 실제 disabled cancel을 함께 적용한다.
- **Library client data**: `LibraryProvider`만 organization version/scope/page window와 summary-work/organization-pending freshness를 소유한다. Higher/lower revision 규칙, mutation/resource operation epoch, endpoint별 abort를 우회해 component local cache를 만들지 않는다. `libraryClient.ts`의 max 5 pages/500 entities와 canonical URL resolver를 재사용한다. Health는 기존 singleton hook을 계속 사용한다.
- **Library move**: Meeting 이동은 `PATCH /api/meetings/[id]/location`, folder reparent는 분리된 `PATCH /api/folders/[id]/parent`만 사용한다. Pure reducer post-condition과 expected generation+revision, latest live scan, destination strictness를 우회하지 않는다. Artifact path를 바꾸거나 stale destination을 fallback하지 말고 existing user placement가 finalize receipt보다 우선한다.
- **Preservation container delete**: Folder/workspace delete는 preview와 commit을 분리하고 `libraryContainerDelete` pure calculator/reducer를 둘 다 사용한다. Commit은 latest scan+pending receipt를 queue 안에서 다시 계산한다. Folder는 direct placement rehome+child promote, workspace는 destination unfiled rehome+default transition이며 meeting directory/artifact나 immutable finalize receipt를 삭제·rewrite하지 않는다.
- **Recovery planner/executor 분리**: `libraryRecoveryIntent`는 path 없는 strict semantic intent와 recoveryId-derived basename만 정의하고, `libraryRecoveryPlanner`는 typed observation을 pure decision으로 바꾼다. `libraryRecoveryExecutor`만 같은 library queue에서 private archive/publish/restore side effect를 수행한다. Intent phase는 atomic replace하고 unsafe/multiple/mismatch/unknown state를 cleanup/bootstrap으로 낮추지 않는다. `/api/library/rebuild`는 corrupt fingerprint 외 path/name/recoveryId를 받지 않는다(ADR 0017).
- **Activated library UI**: `LibraryNavigation`은 desktop rail/native top-layer mobile drawer와 workspace/folder create/edit·same-workspace folder move·preservation delete를 소유한다. Native workspace `<select>`와 aria-hidden chevron, folder disclosure/scope/edit/create의 독립 44px target을 같은 navigation markup에서 유지하고, interactive kebab/chevron/plus/menu/close는 `InlineIcons.tsx`의 shared SVG만 쓴다. `HomeClient`는 canonical scope와 provider page, 16px→24px gutter, banner/empty-state reflow를 렌더하고 queryless legacy list를 count source로 쓰지 않는다. `MeetingRow`/`EditableTitle`은 card 밖 kebab, `w-full min-w-0` long-content ownership, mobile stacked edit/delete, IME-safe Enter와 실패 focus 보존을 소유한다. `LibraryLocationPicker`는 meeting cross-workspace와 folder same-workspace intent를 구분하고 `ContainerDeleteDialog`는 preview token/name confirmation/IME guard를 소유한다. Scoped detail은 `detailSource.ts`의 structured IDs만 검증하며 raw `returnTo`/client names를 사용하지 않는다. Ready/last-good scope recorder는 immutable ID destination을 전달하고 global fallback만 no-location으로 시작한다. `LibraryRecoveryPanel`은 corrupt-only rebuild, recorder Blob gate, exact IME confirmation을 소유하고 success는 provider generation reset 뒤 new default All로 이동한다.
- **Detail/Tabs/review**: `Tabs.tsx`는 horizontal few-tab ARIA relationships와 Left/Right wrap·Home/End automatic activation만 소유하고 feature data를 갖지 않는다. Detail utility sibling은 같은 44px rectangular group이며 audio/review가 tabs 앞에 온다. Review success body를 검증해 local current participants를 갱신하되 dirty input은 parent refresh로 덮지 않는다. Component 회귀는 `components/__tests__/Tabs.test.tsx`와 `components/__tests__/views.test.tsx`에 둔다.
- **Glossary/Settings form state**: Initial GET은 `loading|ready|load_error`를 구분하고 non-2xx/network/invalid body를 empty/default로 낮추지 않는다. Retry/unmount는 이전 GET을 abort하고 load error에서는 replace-style save를 노출하지 않는다. Glossary는 shared `Tabs`와 explicit dirty save를 사용하고, Settings는 server-confirmed snapshot과 normalized draft를 분리해 dirty일 때 connection test를 막는다. Settings health는 persisted configuration만 검사하며 결과 context에 provider/model만 쓰고 baseUrl은 노출하지 않는다.
- **Recorder live announcements**: Full/compact recorder의 timer·meter·action subtree를 live region으로 감싸지 않는다. `recorderPhaseAnnouncement()`의 dedicated polite status만 lifecycle phase 전환을 알리고 시각 timer/meter semantics는 그대로 유지한다.
- **Audio read route**: `api/meetings/[id]/audio/route.ts`는 guard/fence/read-lease 순서를 유지한 채 no-range `200`, single range `206`, invalid/empty `416` headers를 조립한다. `lib/audioStream.ts`만 range normalization과 abort/cancel/end/close/error release-once adapter를 소유한다. Route bytes/headers는 `api/__tests__/routes.integration.test.ts`, cancel/abort race는 `api/__tests__/audioStream.test.ts`, tombstone ordering은 `api/__tests__/tombstoneFence.test.ts`에서 검증한다.
- **아티팩트 쓰기**: 항상 `src/lib/atomicWrite.ts` 또는 정책을 노출하는 `src/lib/durableFileOps.ts`(temp→file fsync→rename→parent fsync) 경유. rename 이후 sync 실패는 committed/pending으로 처리하며 원본(`audio.webm`/`raw.md`)은 수정 금지.
- **Library registry**: `src/lib/library.ts`만 `data/library.json`을 쓴다. absolute-path process queue, `libraryId+revision`, read mode, bootstrap/reconcile/last-good 계약을 우회하지 않는다. 모든 scanner는 typed observation을 만든 뒤 `classifyMeetingRecord()`를 정확히 한 번 호출한다.
- **요약 파싱/발행**: `summarizeCore.ts`는 path/I/O 없이 payload만 만든다. Canonical pair는 `summarizePublisher.ts`만 내구 staging 후 발행한다. 상세/export는 `readArtifactPair()`, 폴더 삭제/cleanup은 operation owner로 artifact write lease를 잡은 뒤 수행한다. Pair read lease 안에서 status/library를 mutation하지 말 것.
